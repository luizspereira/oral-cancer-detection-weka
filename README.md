# oral-cancer-detection-weka
Projeto de pesquisa para detecção precoce de cancêr bucal utilizando Inteligência Artificial e algoritmos de aprendizado de máquina no ambiente WEKA.
# Detecção de Câncer Oral em Imagens Clínicas

Este projeto aplica técnicas de Inteligência Artificial para auxiliar na triagem e diagnóstico precoce de câncer bucal.

# Metodologia
- Base de dados: [Oral Cancer Images - Kaggle](https://www.kaggle.com/datasets/muhammadatef/oral-cancer-images-for-classification)
- Extração de atributos: LeNet pré-treinada (Transfer Learning)
- Balanceamento: SMOTE
- Classificação: Random Forest, J48, Bayes Net e Multilayer Perceptron
- Ambiente: WEKA

## Resultados
- Melhor modelo: **Random Forest (50 árvores)**
- Acurácia: **79,17%**
- Índice Kappa: **0,5833**
- AUC: **0,85**
